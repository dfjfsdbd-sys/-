# المنظومة الإنتاجية — دليل الرفع على GitHub Pages

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كاملاً (HTML و CSS و JavaScript في ملف واحد) |
| `manifest.json` | يعرّف المتصفح باسم التطبيق وأيقوناته وألوانه حتى يُثبَّت كتطبيق |
| `sw.js` | Service Worker — يجعل التطبيق يعمل بلا إنترنت |
| `icon-192.png` `icon-512.png` | أيقونات التطبيق الأساسية |
| `maskable-192.png` `maskable-512.png` | نسخ تملأ الإطار كاملاً (أندرويد يقصّها بأشكال مختلفة) |
| `icon-180.png` | أيقونة آيفون وآيباد |
| `icon-32.png` | أيقونة تبويب المتصفح |

**كل الملفات تُرفع في نفس المجلد، بنفس الأسماء تماماً.** المسارات داخلها نسبية، فلا تحتاج أي تعديل.

---

## الرفع — الطريقة الأسهل (من المتصفح، بلا أي برامج)

**1. أنشئ مستودعاً جديداً**

ادخل [github.com/new](https://github.com/new)، سمِّ المستودع مثلاً `montheoma`، اختر **Public** (الخيار المجاني الوحيد الذي يدعم Pages)، ثم **Create repository**.

**2. ارفع الملفات**

في صفحة المستودع اضغط **Add file** ثم **Upload files**، واسحب ملفات هذا المجلد **التسعة** دفعة واحدة. اكتب أي وصف في خانة التعليق ثم اضغط **Commit changes**.

**3. فعّل GitHub Pages**

من **Settings** ← **Pages** في القائمة اليمنى:
- تحت *Source* اختر **Deploy from a branch**
- تحت *Branch* اختر **main** والمجلد **/ (root)**
- اضغط **Save**

انتظر دقيقة أو دقيقتين، ثم حدّث الصفحة — سيظهر رابطك بالشكل:

```
https://اسم-حسابك.github.io/montheoma/
```

## تثبيت التطبيق على الهاتف

**أندرويد (كروم):** افتح الرابط ← قائمة النقاط الثلاث ← **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.

**آيفون (سفاري — ولا بد أن يكون سفاري تحديداً):** افتح الرابط ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

بعد التثبيت يفتح التطبيق بملء الشاشة بلا شريط عنوان، ويعمل بلا إنترنت.

---

## لماذا الرابط مهم أكثر مما تظن

الحسّاسات وأذونات المتصفح **لا تعمل إلا على اتصال آمن (https)**. رابط GitHub Pages مؤمَّن دائماً، ولهذا ستعمل عليه أشياء لم تعمل عندك سابقاً حين كنت تفتح الملف من التخزين:

- **الدوران التلقائي** لمؤقت البومودورو عند قلب الهاتف
- **الكاميرا داخل التطبيق** لالتقاط صور المهام
- **الإشعارات**

---

## تحديث التطبيق لاحقاً

ارفع `index.html` الجديد فوق القديم (Add file ← Upload files ← Commit). التطبيق يجلب الصفحة من الشبكة أولاً، فيصلك التحديث عند أول فتح.

إن غيّرت `sw.js` أو الأيقونات، ارفع رقم النسخة داخل `sw.js`:

```js
const CACHE_VERSION = 'v2';   // كان v1
```

هذا يمسح الذاكرة القديمة ويجبر المتصفح على جلب كل شيء من جديد.

---

## تنبيه مهم حول بياناتك

بيانات التطبيق (المهام، المكتبة، سجلّ الإنجاز) محفوظة في **ذاكرة المتصفح على جهازك**، لا على GitHub. وهذا يعني:

- **لا أحد يراها غيرك** حتى لو كان المستودع عاماً — المرفوع هو الكود فقط.
- **لا تنتقل بين الأجهزة** تلقائياً.
- **تُمسح إن مسحت بيانات الموقع** من إعدادات المتصفح.

استخدم **تصدير نسخة احتياطية** من صفحة الروتين بين حين وآخر، واحفظ الملف في مكان آمن. الاستيراد من نفس المكان.

## إن لم يعمل شيء

| المشكلة | السبب الغالب |
|---|---|
| الرابط يعطي 404 | انتظر دقيقتين إضافيتين، أو تأكد أن `index.html` في جذر المستودع لا داخل مجلد |
| لا يظهر خيار التثبيت | تأكد أن `manifest.json` مرفوع بنفس الاسم وفي نفس المجلد |
| التغييرات لا تظهر | أغلق التطبيق وافتحه، أو ارفع رقم النسخة في `sw.js` |
| الكاميرا أو الدوران لا يعملان | تأكد أنك تفتح رابط `https` لا ملفاً محلياً، وأنك سمحت بالإذن عند طلبه |

# المنظومة الإنتاجية — ملفات الرفع

## كيف ترفعها على GitHub

**ارفع الملفات التسعة فوق القديمة بنفس الأسماء. لا تحذف شيئاً أولاً.**

GitHub يستبدل الملف تلقائياً حين ترفع ملفاً بالاسم نفسه، وهذا أسلم من الحذف ثم الرفع (الحذف يوقف الموقع لدقائق ويكسر الروابط مؤقتاً).

الخطوات:

1. افتح صفحة المستودع
2. **Add file** ← **Upload files**
3. اسحب الملفات التسعة كلها دفعة واحدة
4. **Commit changes**

خلال دقيقة أو دقيقتين يتحدّث الموقع.

---

## بعد الرفع — خطوة ضرورية مرة واحدة

**احذف التطبيق المثبّت من هاتفك وثبّته من جديد.**

السبب: `manifest.json` تغيّر في هذا التحديث (إخفاء شريط الحالة، وقفل الاتجاه العمودي)، وأندرويد يقرأ هذا الملف **عند التثبيت فقط**. بدون إعادة التثبيت سيبقى التطبيق على إعداداته القديمة.

بياناتك لا تُمسح بإزالة التطبيق — هي محفوظة في ذاكرة المتصفح لا في التطبيق نفسه. ومع ذلك: **صدّر نسخة احتياطية قبل أن تبدأ**، من صفحة الروتين ← الإعدادات ← أيقونة التصدير.

## الملفات

| الملف | ملاحظة |
|---|---|
| `index.html` | التطبيق كاملاً — هذا ما يتغيّر في كل تحديث |
| `manifest.json` | تغيّر في هذا التحديث |
| `sw.js` | تغيّر في هذا التحديث (رقم النسخة `v2`) |
| `icon-192.png` `icon-512.png` | أيقونات التطبيق |
| `maskable-192.png` `maskable-512.png` | نسخ تملأ الإطار (أندرويد يقصّ الأيقونة بأشكال مختلفة) |
| `icon-180.png` | أيقونة آيفون |
| `icon-32.png` | أيقونة تبويب المتصفح |

## في التحديثات القادمة

إن تغيّر `index.html` وحده، ارفعه وحده. يصلك التحديث عند أول فتح لأن التطبيق يجلب الصفحة من الشبكة أولاً ويعود للنسخة المخزّنة عند انقطاع الإنترنت.

إن تغيّر `sw.js` أو الأيقونات، ارفع رقم النسخة داخل `sw.js`:

```js
const CACHE_VERSION = 'v3';   // كان v2
```

هذا يمسح الذاكرة القديمة ويجبر المتصفح على جلب كل شيء من جديد.

---

## ما يعمل على الرابط ولا يعمل على الملف المحلّي

الحسّاسات وأذونات المتصفح تحتاج اتصالاً آمناً (https)، ورابط GitHub Pages مؤمَّن دائماً:

- **الدوران التلقائي** لمؤقّت البومودورو عند قلب الهاتف
- **الكاميرا داخل التطبيق** لالتقاط صور المهام
- **الإشعارات**

---

## بياناتك

محفوظة في **ذاكرة المتصفح على جهازك**، لا على GitHub. المرفوع هو الكود فقط، فلا أحد يرى مهامك حتى لو كان المستودع عاماً. لكن هذا يعني أيضاً أنها تُمسح إن مسحت بيانات الموقع، ولا تنتقل بين الأجهزة.

**صدّر نسخة احتياطية بين حين وآخر** واحفظ الملف في مكان آمن.
